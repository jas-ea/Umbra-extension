# Security

Umbra runs on webpages through the broad host access required by its single purpose. Handle reports about permission use, script injection, storage, or page isolation privately.

Send security reports to [hi@cassiniresearch.com](mailto:hi@cassiniresearch.com) with the subject `Umbra security`. Do not include exploit details, private page content, or account information in a public issue.

Include the affected Umbra version, Chrome version, operating system, a minimal reproduction, and the impact. Cassini Research will acknowledge a complete report and coordinate a fix before public disclosure.

General site-targeting bugs can use the public issue tracker when the report contains no private data.
