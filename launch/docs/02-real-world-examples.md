# Umbra on Real Websites

These screenshots show Umbra running on public websites on August 17, 2026. Each image was captured after automatic selection completed. They are product states, not mockups.

## Read technical documentation

![Umbra on Chrome Developers permissions documentation](../assets/screenshots/chrome-developers-permissions.png)

**Website:** [Chrome Developers permissions documentation](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions)

**Task:** Read the explanation of optional permissions while retaining access to the article navigation and table of contents.

**Result:** The current paragraph remains clear. The two navigation systems, page header, and surrounding code reference become darker.

## Scan an issue queue

![Umbra on the OpenAI Cookbook issue list](../assets/screenshots/github-openai-cookbook-issues.png)

**Website:** [OpenAI Cookbook issues](https://github.com/openai/openai-cookbook/issues)

**Task:** Scan issue titles and metadata as one working list.

**Result:** The issue collection remains clear as a unit. Repository navigation, filters, and side controls become darker. Umbra intentionally avoids isolating one row while the user scans the queue.

## Capture standard

Public screenshots must show the automatic product state, enough surrounding interface to make the effect visible, and no private account data. Captions must identify the website, the task, and the visible result. Recheck third-party content before every publication.
