# Umbra keeps one block clear on busy webpages

A busy page can be useful and difficult to follow at the same time. Chat apps, technical documentation, issue lists, and feeds put the current item beside navigation, filters, composers, and repeated rows.

Umbra adds one visual layer to that page. It dims the area around a selected block while leaving the website in place and interactive. There is no separate reader view and no rewritten page.

Automatic focus waits until the pointer rests on a block or scrolling settles. It keeps the current block visible while confirming the next one, then moves the rounded cutout as one continuous shape. When the automatic choice is wrong, Choose an area lets the user click the block directly. The popup also controls surrounding darkness, site behavior, and tab pause.

The difficult part is deciding what counts as a block. On a chat page, the answer should win over the full conversation shell, sidebar, toolbar, and composer. On a feed, a post should win over the timeline wrapper, promoted cards, and message drawer. We test those layouts directly, including adjacent-item switching, control clicks, nested scrolling, and clipped edges.

Umbra processes page structure locally. It does not send page content, URLs, pointer history, or usage analytics to Cassini Research. Preferences are stored through Chrome storage.

Umbra is being prepared for the Chrome Web Store by Cassini Research.
